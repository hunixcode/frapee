## Description 

A simple portfolio made with React + Vite, this page features hand-made sections, re-used components showcasing
expertise in modules/components management.

## How to run this project locally

```sh
npm i

npm run dev
```

if you want to build the dist folder on your machine run

```sh
npm run build
```

you'll be served a `dist/` folder containing the built project
